One line: the museum label a museum in the year 3000 puts beside an ordinary object from today. The program validates the label (1–200 characters, single line, printable ASCII) and writes it to `entry.txt` in the output directory.

## Run it

```
node main.ts
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
